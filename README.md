# Framedge website

Static website for framedge.com, migrated from Squarespace. GitHub Pages publishes the main branch root. No build step or paid hosting is required.

The site uses relative internal links, locally hosted original media, and a client-side email composer for demo requests. The form opens the visitor’s email app; it does not silently submit data. YouTube loads only after the visitor chooses to play a demo. Existing API reference endpoints are retained, but current API/SDK access is handled through hello@framedge.com.

Pages: home, team, demo, avocado, privacy, terms. The existing legal text is preserved. Original images and GIFs remain in assets; MP4 versions of the two GIF demonstrations are served for efficient playback. Sample API input files retain their /s/ paths.
